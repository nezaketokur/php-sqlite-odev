# Kahve Kataloğu — PHP & SQLite Projesi

Bu proje, PHP ve SQLite kullanılarak geliştirilmiş bir kahve kataloğu web uygulamasıdır.

## Klasör Yapısı
- `assets/` : CSS ve görsel tasarım dosyaları (`style.css`)
- `database/` : SQLite veritabanı dosyası (`kahve.db`)
- `includes/` : Veritabanı bağlantı dosyası (`baglanti.php`)
- `index.php` : Ana sayfa ve kahve listeleme ekranı

## Çalıştırma
Proje dizininde yerel sunucuyu başlatmak için terminalde şu komutu çalıştırın:

    php -S localhost:8000

Tarayıcıdan `http://localhost:8000` adresine giderek uygulamayı görüntüleyebilirsiniz.
